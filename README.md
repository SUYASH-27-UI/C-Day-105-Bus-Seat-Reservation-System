# C Day 105 - Bus Seat Reservation System

## Description
A menu-driven bus reservation application developed in C. It manages seat availability and passenger reservations using file handling.

## Features
- Display 20 seat statuses
- Reserve available seats
- Prevent duplicate seat bookings
- Search reservations by seat number
- Cancel existing reservations
- Store booking records permanently

## Files
- `bus.c` - Main C program
- `reservations.txt` - Sample reservation records

## Requirements
- GCC compiler

## How to Compile
```bash
gcc bus.c -o bus
```

## How to Run
On Windows:
```bash
bus.exe
```

Keep `reservations.txt` in the same folder as the executable.

## Concepts Used
- Structures
- Functions
- File handling
- Searching records
- Temporary files
- File deletion and renaming
